طريقة الحصول على ملف APK بدون Android Studio:
1) أنشئ حساباً على github.com ثم مستودعاً جديداً (New repository).
2) ارفع كل محتويات هذا المجلد (Add file > Upload files) مع مجلد .github.
3) ادخل تبويب Actions > Build APK > Run workflow.
4) بعد دقائق افتح التشغيل الناجح وحمّل notes-apk من قسم Artifacts، وفك الضغط لتجد app-debug.apk وثبّته على هاتفك.
